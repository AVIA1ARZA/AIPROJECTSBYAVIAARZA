# מתמלל שיחות

מעלים הקלטת שיחה (AMR ועוד) ומקבלים **תמלול בעברית עם הפרדה לדוברים**, כקובץ טקסט.

```
דובר 1 [00:00]:
שלום, מדברת מחברת הביטוח. אפשר לדבר עם מר כהן?

דובר 2 [00:06]:
כן, זה אני. במה מדובר?
```

## הרצה

**דרישות:** Node.js 20.12 ומעלה, ומפתח Gemini API ([יצירת מפתח](https://aistudio.google.com/apikey)).

1. `npm install`
2. מעתיקים את `.env.example` לקובץ בשם `.env` ומדביקים את המפתח אחרי `GEMINI_API_KEY=`
3. `npm start` ופותחים את http://localhost:3000
4. גוררים קובץ הקלטה, לוחצים "התחלת תמלול", ובסוף "הורדת קובץ טקסט".

אין צורך להתקין ffmpeg: הוא מגיע עם `npm install` (חבילת `ffmpeg-static`).

### משורת פקודה

```
node cli.js שיחה.amr                    # נשמר ל-שיחה-תמלול.txt ליד הקובץ
node cli.js שיחה.amr -o תמלול.txt --no-timestamps
```

## איך זה עובד

1. **המרה:** ffmpeg מפענח את הקובץ (AMR-NB, AMR-WB, 3GP, M4A, MP3, WAV...) למונו 16kHz. ל-Gemini אין תמיכה רשמית ב-AMR, ולכן ההמרה היא שלב חובה.
2. **חלוקה:** הקלטות ארוכות נחתכות לקטעים של כ-15 דקות, תמיד באמצע שקט ולא באמצע משפט.
3. **תמלול והפרדת דוברים:** כל קטע נשלח ל-Gemini (ברירת מחדל `gemini-3.5-flash`) עם הנחיות לתמלול מילולי בעברית, זיהוי דוברים לפי קול וזמן התחלה לכל קטע דיבור. לקטעים הבאים מצורפות השורות האחרונות של הקטע הקודם, כדי ש"דובר 1" יישאר "דובר 1" לאורך כל השיחה.
4. **הרכבה:** התוצאה מורכבת לקובץ UTF-8 (עם BOM, כדי ש-Notepad יציג עברית נכון). שגיאות זמניות של Gemini (עומס, 503) נוסות שוב אוטומטית.

## חשוב לדעת

- **פרטיות:** האודיו נשלח ל-Gemini API של Google. אם ההקלטות רגישות (לקוחות, מידע רפואי או פיננסי), כדאי לבדוק את תנאי השימוש בנתונים של סוג המפתח שלך. בחלק מהמסלולים החינמיים Google רשאית להשתמש בתוכן לשיפור המוצרים שלה.
- **דיוק:** הפרדת הדוברים נעשית על ידי המודל, ולא באלגוריתם ייעודי. בשיחת שניים היא בדרך כלל טובה, אבל קולות דומים או דיבור חופף עלולים להתבלבל. שמות, מספרי טלפון וסכומים כדאי לבדוק מול ההקלטה.
- **דוברים:** התוצאה היא "דובר 1", "דובר 2" וכן הלאה, בסדר הופעה, ולא שמות אמיתיים.
- **עלות:** התמלול נחשב על חשבון מפתח ה-API שלך, לפי אורך ההקלטה.
- השרת מאזין רק למחשב המקומי (`127.0.0.1`), כי כל תמלול חייב מפתח. לא מומלץ לחשוף אותו לרשת בלי הגנה.

## הגדרות (קובץ `.env`)

| משתנה | ברירת מחדל | משמעות |
|---|---|---|
| `GEMINI_API_KEY` | – | מפתח ה-API (חובה) |
| `GEMINI_MODEL` | `gemini-3.5-flash` | מודל Gemini לתמלול |
| `PORT` / `HOST` | `3000` / `127.0.0.1` | כתובת השרת |
| `FFMPEG_PATH` | ffmpeg מהחבילה | נתיב ל-ffmpeg אחר, אם צריך |

## בדיקות

`npm test` מריץ בדיקות על כל הצינור (פענוח AMR, חלוקה לקטעים, ניסיונות חוזרים, השרת) מול לקוח Gemini מדומה, בלי מפתח ובלי רשת.
